# API E-Commerce  
**Evidencia GA7-220501096-AA5-EV03**  
Diseño y desarrollo de servicios web – proyecto

## Descripción

API REST para un sistema de **E-commerce** que incluye:

- Autenticación (registro e inicio de sesión)
- Categorías
- Productos (CRUD completo)
- Pedidos

## Tecnologías

- Node.js (módulo nativo `http`)
- Almacenamiento en archivos JSON
- Git para control de versiones

## Ejecución

```bash
node server.js
```

Servidor: **http://localhost:3000**

## Documentación

Ver el archivo **DOCUMENTACION_API.md** para el detalle completo de cada servicio y endpoint.
